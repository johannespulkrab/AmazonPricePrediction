# AmazonPricePrediction

This project was developed as part of the Applied Machine Learning for Language Processing course. The objective was to build and evaluate machine learning models to predict optimal product prices on Amazon based on structured and textual features.

## Dataset

We used the USA Optimal Product Price Prediction Dataset (1.6M entries, scraped from Amazon US). It includes product titles, categories, reviews, bestseller status, and prices.

Models Implemented
	•	LightGBM and XGBoost
	•	Baseline models: Linear, Ridge and Lasso Regression for comparison
